TES 事件能量的微分方程推导

从零基础出发 · 纯符号推导,不代入任何数值 · 依据 Irwin & Hilton, Transition-Edge Sensors (2005)

第 0 节 · 预备知识(只需要这五件事)

(0) 记号约定:(δI)² 不是 δ(I²)。本文一律把偏移量写成 δI ≡ I − I0,并把"偏移量的平方"写成 (δI)²(始终加括号)。它与"平方的偏移量"是两个不同的量:

(δI)² = (I − I0)²    δ(I²) ≡ I² − I0² = 2I0δI + (δI)²

两者差一整项 2I0δI,而这一项恰好是本文线性项的主要来源, 所以绝不能混。下文所有平方都写成 (δI)² 形式,凡出现 δ(I²) 都会显式写出括号内的展开。

(1) 导数与积分。df/dt 表示 f 随时间的变化率;∫f dt 是曲线下的面积。本文用记号 ḟ ≡ df/dt。

(2) 两个积分恒等式。对任意函数 δI(t):

∫0tf δİ dt = δI(tf) − δI(0) ,   ∫0tf δI·δİ dt = ½[(δI)²(tf) − (δI)²(0)]

第二条来自 δI·δİ = ½ d[(δI)²]/dt。含义:被积函数是"某个量的导数"时,积分只剩端点值(边界项)。这是全文最常用的一招。

(3) 一阶泰勒展开。函数在工作点附近的小偏移可用切线近似:f(x0+δx) ≈ f(x0) + f′(x0)·δx,误差是二阶小量 𝒪((δx)²)。

(4) 电路两定律。基尔霍夫电压定律(KVL):沿回路电压代数和为零。元件电压:电阻 VR = IR;电感 VL = L dI/dt。电阻上的耗散功率 P = I²R。

(5) 热学两概念。热容 C:温度变化需要的能量,C dT/dt = 净输入功率;热导:器件通过热连接向低温热库(bath)漏热,功率记 Pbath(T),其斜率 G ≡ dPbath/dT。

第 1 节 · 物理装置与电路图

TES(Transition-Edge Sensor)是一片偏置在超导转变边缘的薄膜:温度略升,电阻 RTES 陡增。事件沉积能量 → 薄膜升温 → 电阻升高 → 回路电流改变。我们测到的就是电流波形 I(t),要反推的是沉积能量 E。

由电路等效变换(戴维南定理)得到本文的基本定义:

(1) V = IbRsh ,  RL = Rp + Rsh ,  I0 = VRL + R0 ,  I(t) = I0 + δI(t)

其中 R0 为工作点的 TES 电阻,I0 为静态电流,δI(t) 为脉冲引起的偏移(即测量到的波形,已扣基线并换算为电流)。

第 2 节 · 两条微分方程从哪里来

2.1 电学方程(对图 2 用 KVL)

沿回路:电源电压 = 三个元件电压之和:

(2) V = I RL + Lİ + I RTES(T, I)  ⇔  LdIdt = V − I RL − I RTES(T, I)

注意 RTES 依赖温度与电流——这是电与热耦合的入口。

2.2 热学方程(对 TES 薄膜记能量账)

薄膜温度变化 = 流入功率减流出功率。流入:焦耳加热 PJ = I²RTES 与事件信号功率 P(t);流出:漏向热库的 Pbath(T):

(3) CdTdt = −Pbath(T) + PJ + P(t)
问题陈述:已知测量波形 δI(t) 与常数 V, RL, R0, I0, L,求事件沉积进 TES 的总能量 E = ∫P(t)dt。

第 3 节 · 第一步:热方程积分(严格,无近似)

把 (3) 中的 P 解出来并对 [0, tf] 积分。定义各量相对稳态的偏移(稳态满足 0 = −Pbath(T0) + PJ0),相减后:

(4) E = ∫P dt = C·δT |0tf + ∫ ΔPbath dt − ∫ δPJ dt

三项含义:截止时刻还存在薄膜里的热(边界项);脉冲期间多漏给热库的能量;焦耳加热的减少量(负反馈:电阻升高 → 电流下降 → 焦耳热下降,"腾出"的加热正好补偿吸收的能量)。若积到脉冲完全衰减,第一项为零。

第 4 节 · 第二步:焦耳项的精确展开(严格,无近似)

关键观察:焦耳功率 PJ = I²RTES 中的未知量 RTES 可以用电学方程 (2) 整体消去:

(5) I RTES = V − I RL − L İ  ⇒  PJ = I(V − I RL − L İ)

代入 I = I0 + δI 并逐项展开(注意 İ = δİ):

PJ = I0V + VδI − RL(I0² + 2I0δI + (δI)²) − L(I0+δI)δİ

稳态(事件未发生)时 δI = 0、δİ = 0,代入上式即得 PJ0 = I0V − I0²RL (电感项因 İ = 0 而消失)。按定义 δPJ ≡ PJ − PJ0, 常驻项 I0V 与 I0²RL 逐一抵消,只剩事件引起的变化:

δPJ = (V − 2I0RL)·δI − RL·(δI)² − L(I0+δI)δİ

能量方程 (4) 里出现的是 −δPJ(焦耳功率的减少量才是事件能量的来源),整式乘 −1:

(6) −δPJ = (2I0RL − V)·δI + RL·(δI)² + L(I0+δI)δİ

注意二次项来自 RLδ(I²) = RL[2I0δI + (δI)²] 的后一半: 前一半 2I0RLδI 已经并入线性系数。这正是记号必须写成 (δI)² 的原因 (见第 0 节 (0)),也是 Method 1 把二次系数写成 2RL 的疑似来源。

用定义 V = I0(RL+R0) 化简线性系数:2I0RL − V = I0(RL − R0)。积分时,末项恰是"某量的导数"(预备知识 (2)),只剩端点值:

(7) −∫0tf δPJ dt = I0(RL−R0)∫δI dt + RL∫(δI)² dt + L[I0δI + ½(δI)²]0tf

物理解释:电感边界项 = 电感储能 ½L I² 在窗口首尾的差;积到完全衰减(δI→0)时它为零。至此没有用过任何近似。

第 5 节 · 第三步:bath 项(全文唯一的线性化)

5.1 三个标准无量纲参数(Irwin 的定义)

(8) αI ≡ T0R0∂R∂T ,  βI ≡ I0R0∂R∂I ,  ℒ ≡ PJ0 αIG T0 (回路增益), PJ0 = I0²R0

5.2 由电阻反推温度

对 R(T, I) 做一阶泰勒展开并用 (8) 改写偏导:

(9) δR = R0αIT0δT + R0βII0δI  ⇒  δT = T0R0αI[ δR − R0βII0δI ]

而 δR(t) 本身可以由电学方程从数据逐点重建(同样严格):

(10) δR(t) = V − I RL − L İI − R0

5.3 漏热的线性化与参数坍缩

ΔPbath ≈ GδT(一阶展开,误差 𝒪((δT)²))。妙处在于组合 G T0/αI 可用回路增益整体表示:由 (8),G T0/αI = PJ0/ℒ = I0²R0/ℒ,于是 C、G、αI、T0 全部坍缩进一个 ℒ:

(11) ∫ΔPbath dt = I0²ℒ∫δR dt − I0R0βIℒ∫δI dt

同理,(4) 中的热容边界项用 C = Gτ(τ ≡ C/G 为自然热时间常数)化为:

(12) CδT(tf) = τI0²ℒ[ δR − R0βII0δI ]t=tf

第 6 节 · 总公式

把 (7)(11)(12) 代回 (4):

E = I0(RL−R0)∫δI dt + RL∫(δI)² dt + L[I0δI + ½(δI)²]0tf
  + I0²ℒ∫δR dt − I0R0βIℒ∫δI dt + τI0²ℒ[ δR − R0βII0δI ]tf
项物理含义需要的参数性质
第 1、2 项焦耳加热减少量(ETF 主项)I0, RL, R0严格
第 3 项电感储能的窗口边界差+ L严格
第 4、5 项脉冲期间多漏给热库的能量+ ℒ, βI一阶(误差 𝒪((δT)²))
第 6 项截止时刻还存在薄膜里的热+ τ一阶

第 7 节 · 准静态近似与单系数形式

电感很小(电学时标 ≪ 热学时标)时,可在 (2) 中取 L→0:I = V/(RL+RTES)。对 RTES 求导:

(13) δI = −V(RL+R0)²δR = −I0RL+R0δR  ⇒  δR = −RL+R0I0δI

代入 (11) 的第一项并与总公式第 1 项相比(取 βI≈0),bath 项与主项之比为常数,于是:

E ≈ [ 1 + R0+RLℒ(R0−RL) ] × EJoule

即:整套三级修正在小信号极限下坍缩为对焦耳项乘一个只含 ℒ 的系数。

附录 A · 双指数脉冲形状从哪里来

把 (2)(3) 在工作点线性化,得到关于 (δI, δT) 的 2×2 线性常微分方程组。二阶线性系统有两个特征值,记 −1/τ₊ 与 −1/τ₋,通解是两个指数的线性组合。对"瞬时能量注入"(δ 函数)的响应即:

δI(t) ∝ e−t/τ₊ − e−t/τ₋

——这正是模板拟合所用的双指数形状:快时标 τ₊ 主导上升(电学,∼L/R),慢时标 τ₋ 主导下降(热学,∼C/G 经反馈缩短)。两条时间常数满足:

1τ₊ + 1τ₋ = 1τel + 1τI ,  1τ₊τ₋ = 1τelτI + R0ℒ(2+βI)Lτ

其中 τel = L/[RL+R0(1+βI)],τI = τ/(1−ℒ)。推论:测得每个通道的 τ₊、τ₋(来自脉冲拟合),在给定 L、βI≈0 的条件下,这两条方程即可反解出 ℒ 与 τ——信号脉冲本身可以充当 dIdV 的替代探针。

附录 B · dIdV(复阻抗)如何给出全部参数

在偏置线上加小交流激励,按频率测电流响应,得复阻抗 Z(ω) = Vω/Iω。线性化系统给出解析形状:

Z(ω) = RL + iωL + ZTES(ω) ,  ZTES(ω) = R0(1+βI) + R0ℒ1−ℒ·2+βI1+iωτI

对实测 Z(ω) 曲线拟合 → 直接得到 βI, ℒ, τI, L;再由 ℒ 的定义解出 αI,由 τ = τI(1−ℒ) 与 C = Gτ 得到 C、G。总公式所需的全部参数由此闭合。
